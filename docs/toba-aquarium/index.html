01 / ROUTE

迷わない3時間ルート

LゾーンのイベントとIゾーンのラッコを時刻の柱にします。入館時にラッコ列の長さを見て、12:20〜12:45の枠だけ柔軟に前後させるのがコツです。

!

9/21はシルバーウィーク混雑期間。 チケットを持っていても入館待ちが生じる場合があります。駐車後は寄り道せず入口へ。入館できた時刻が遅れたら、下の「混雑時の分岐」を使います。

  1. 11:15–11:25
    START · ENTRANCE

    入館したら、まず3つ確認

    館内マップを取り、ショー変更の掲示を確認。ラッコ観覧列の状況もスタッフ案内で把握します。

    ふたりで共有：「13時ラッコを守る／14時セイウチ後すぐ出る」を最初に合わせる。

  2. 11:25–11:50
    H · 人魚の海

    ジュゴン「セレナ」をじっくり

    日本で唯一のジュゴン展示。速さを追う場所ではなく、海草を食べる口元、胸びれ、静かな浮上呼吸を待つ場所です。

    楽しみ方：最初の数分は撮影せず、泳ぐリズムをつかんでからお気に入りの瞬間を狙う。

  3. 11:50–12:15
    L · 水の回廊

    12:00 ペンギン散歩

    約10分。目の前を歩く姿を楽しみます。終了後も同じLゾーンにいるため、セイウチや水辺の動物を軽く予習できます。

    立ち位置：通路をふさがず、係員の案内優先。目線を低くすると歩き方がよく見える。

  4. 12:15–12:45
    K / C · DISCOVERY

    へんな生きもの＋古代の海

    K「へんな生きもの研究所」で形と生態の驚きを拾い、C「古代の海」で“生きている化石”へ。企画展の古代生物テーマともつながります。

    調整枠：ラッコ列が長ければ、この30分を列へ回す。空いていれば企画展示室も追加。

  5. 12:45–13:25
    I · 極地の海

    13:00 ラッコのお食事タイム

    13時は「貝のみ」の回。観覧は列に並び、水槽前では約10人ずつ・1分交代です。メイとキラの表情、前足の使い方、食べ方の違いに注目。

    大事：ふたり揃って並ぶ。列の途中合流・場所取りは不可。撮影はフラッシュを切り、まず自分の目で見る。

  6. 13:25–13:50
    E / D · LOCAL SEA

    伊勢志摩の海からサンゴ礁へ

    Eで旅をしている伊勢志摩の海を水中側から眺め、Dの明るいサンゴ礁へ。午前の伊勢観光と午後の水族館が一本につながる区間です。

    時間が押したら：Eを優先し、Dは通り抜け中心でLゾーンへ戻る。

  7. 13:50–14:15
    L → EXIT · FINALE

    セイウチは冒頭だけ → 14:15出発

    14:00のふれあいタイムは約20分。定刻出発を守る今回は、始まりを5分ほど見るか、見送って余裕をもって出口へ向かいます。

    退館判断：13:55時点でLゾーンにいなければ見送る。14:05に出口へ動き、14:15には駐車場を出る。

02 / STARS

会いたい主役たち

「いた！」で終わらず、動きや体のつくりをひとつ観察すると記憶に残ります。

H · 人魚の海

ジュゴン

人魚伝説のモデルともいわれる海生哺乳類。鳥羽水族館は国内唯一の展示です。

  • 海草を口で集める食べ方
  • 浮上して呼吸する間隔
  • 胸びれと尾びれの動き
I · 極地の海

ラッコ

メイとキラの2頭。1分の観覧だからこそ、見るテーマをひとつ決めておきます。

  • 貝を持つ前足の器用さ
  • 毛づくろいで保温する姿
  • 顔・ひげ・毛色の違い
L · 水の回廊

セイウチ

巨体の迫力と、飼育係とのやりとりの細やかさのギャップが魅力です。

  • ひげで周囲を探る様子
  • 大きな体を支える前肢
  • 解説で知る個体の性格
L · 水の回廊

ペンギン

水中の速さとは対照的な陸上の歩き方を至近距離で見られます。

  • 一羽ずつ違う歩幅
  • 列から寄り道する個体
  • 翼を使ったバランス
E · 伊勢志摩の海

スナメリ

伊勢湾にも暮らす小型の鯨類。水面と水中を行き来する滑らかな軌道を追います。

  • 背びれがない丸い背中
  • 短い呼吸の瞬間
  • 水槽内での旋回コース
K · へんな生きもの研究所

変わり者たち

奇妙な形は、生きる場所への適応の結果。「なぜこの形？」をふたりで考える展示です。

  • 名前より先に形を観察
  • 解説板で答え合わせ
  • いちばん不思議な一匹を選ぶ

04 / CHOICES

混雑したときの分岐

3時間は十分に楽しめますが、祝日は「全部見る」より「何を守るか」の判断が大切です。

ラッコ列が30分以内

基本ルートどおり。12:45頃から列へ入り、13:00のお食事タイムを狙います。見終えたらE・Dへ。

ラッコ列が長い

12:15からK・Cへ行かず、そのままIゾーンへ。ラッコを最優先し、E・Dは残り時間で調整します。

入館が11:35以降

Hジュゴンを15分に短縮し、11:50にはLへ。K・Cを省き、ペンギン→ラッコ→セイウチを守ります。

セイウチを最後まで見る

14:20頃に終了し、駐車場出発は14:25頃。熊野市到着も10分ほど後ろ倒しになる前提で、ふたりで選びます。

05 / PRACTICAL

当日に効く実用情報

車・駐車場

9/19〜23は混雑予告期間。第1駐車場は9:00〜17:45、第2立体駐車場は5:00〜17:45。満車時は近隣駐車場へ案内される可能性があります。

  • 普通車はA・Bが1日1,000円、Cは500円
  • 9/20〜22は市民の森臨時駐車場予定（荒天中止あり）
  • 11:15は「駐車」ではなく「入館」の目標時刻

チケット・入館

大人1人2,800円、ふたりで5,600円。WEBチケットは窓口購入を短縮できますが、混雑時の入館待ちはチケットの有無にかかわらず先着順です。

  • 9/21は9:00〜17:30、最終入館16:30
  • 当日に限り、出口で透明スタンプを受ければ再入館可
  • 館内2Fに有料コインロッカーあり

食事・休憩

今回はおかげ横丁で早めの昼食を済ませるため、館内レストランは休憩用の予備。景色ならベイサイド、動物モチーフなら花さんごです。

  • 通常は10:00〜16:30（変更の場合あり）
  • 時間が押したら飲み物だけにして展示を優先
  • 14:15出発後の車内用飲料も入館前に準備

撮影・持ち物

暗い水槽ではフラッシュを切り、スマホをガラスに近づけると反射を減らせます。動画は短く、見る時間も残します。

  • スマホ・モバイルバッテリー
  • 両手が空く小さなバッグ
  • 薄手の羽織り、飲み物、ハンカチ
  • ラッコ観覧では大声・フラッシュ禁止

お土産

中央出入口近くのメインショップと、オリジナルグッズのあるプラザショップがあります。今回は退館がシビアなので先に狙いを決めます。

  • 13:35時点で遅れていなければ10分確保
  • ラッコ・ジュゴンの小物を第一候補に
  • 14:10になったら会計途中でも出発判断

ふたりで楽しむミッション

情報を詰め込むだけでなく、ふたりの発見を持ち帰る小さな遊びです。

  • いちばん癒やされた動物を一匹ずつ選ぶ
  • へんな生きものNo.1を決める
  • 帰りの車でベスト3を発表する
