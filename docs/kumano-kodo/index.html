01 / ROUTE

車を置いて、滝まで歩く

上りは大門坂と大社への参道、下りは青岸渡寺から那智の滝へ。帰りは石畳を戻らず、滝前からバスで駐車場へ戻ります。

!最初に帰りのバス停を確認。 駐車後、「大門坂」バス停の位置と当日の運行情報を見てから歩き始めます。
  1. 8:50–9:15
    START · PARKING

    大門坂駐車場で準備

    無料駐車場に車を置き、トイレ、靴ひも、飲み物を確認。帰りに降りる「大門坂」バス停を見て、入口まで徒歩約3分。

    車内：貴重品を残さず、帰りにすぐ出発できるよう荷物を整理。

  2. 9:15–9:25
    GATE · MEOTO-SUGI

    振ヶ瀬橋から夫婦杉へ

    俗界と聖域の境とされる振ヶ瀬橋を渡り、大門坂茶屋を経て、樹齢約800年とされる夫婦杉の間から古道へ入ります。

    写真：夫婦杉の少し手前から、二本の杉と石畳を一緒に収める。

  3. 9:25–9:55
    STONE PATH · 270 STEPS

    苔むした石畳と多富気王子

    杉木立の中を約640m上ります。石そのものより、段差・濡れた苔・木の根を見て、一段ずつゆっくり進みます。

    楽しみ方：足音、杉の香り、光の差し方を意識。多富気王子は九十九王子最後の王子社。

  4. 9:55–10:10
    APPROACH · 470 STEPS

    商店通りから表参道へ

    大門坂を上り切ると茶屋や土産店の通りへ。ここから熊野那智大社までは、さらに表参道の石段を上ります。

    休憩：息が上がっていたら5分。大社到着後の時間は削らない。

  5. 10:10–10:40
    KUMANO NACHI TAISHA

    熊野那智大社を参拝

    礼殿で参拝し、八咫烏を祀る御縣彦社、樹齢約850年とされる大樟へ。歩いてきた道と、これから向かう滝をつなぐ場所です。

    時間配分：胎内くぐりをする場合は、青岸渡寺へ移る時刻を10:45までに。

  6. 10:40–11:10
    SEIGANTO-JI

    青岸渡寺と三重塔の景色

    隣接する青岸渡寺で本堂を参拝。三重塔と那智の滝が重なる代表的な景色は、少し位置を変えながら楽しみます。

    選択：三重塔内部は大人500円・9:00〜16:00。入るなら10〜15分を見込む。

  7. 11:10–11:25
    DESCENT · WATERFALL

    飛瀧神社へ下る

    青岸渡寺から滝方面へ。ここからは下りですが、石段と舗装路が続くため、膝を急に伸ばさず小さな歩幅で進みます。

    安全：濡れた石段では手すり側。写真は立ち止まってから。

  8. 11:25–12:05
    HIRO-JINJA · NACHI FALLS

    飛瀧神社・那智の滝

    落差133mの那智御瀧そのものが御神体。水の落ち方だけでなく、滝音が森に反響する感覚まで味わいます。

    近くで見る：お滝拝所舞台は参入初穂料が必要。時間と天候を見て選ぶ。

  9. 12:05–12:34
    BUFFER · BUS STOP

    軽食・土産・トイレ → バス停

    12:20までを目安に用事を終え、「那智の滝前」バス停へ。乗車前に行先と「大門坂」停車を確認します。

    締切：12:25にはバス停待機。昼食は車を回収してからでも大丈夫。

02 / HIGHLIGHTS

ただ通り過ぎない見どころ

「有名だから見る」から一歩進んで、何に注目するかをふたりで決めておくと、短いコースが濃い体験になります。

DAIMON-ZAKA

夫婦杉と石畳

大門坂を象徴する入口と、長い時間を刻んだ石の道。参詣者が歩いた道筋を自分の足でたどります。

  • 二本の杉のスケールと間隔
  • 石畳の形が一段ずつ違うこと
  • 朝の光と霧で変わる森の色
KUMANO NACHI TAISHA

八咫烏と大樟

熊野三山の一社。八咫烏は導きの神様として御縣彦社に祀られ、大樟は境内の時間の長さを感じさせます。

  • 朱塗りの社殿と森の対比
  • 御縣彦社の八咫烏
  • 樹齢約850年の大樟
SEIGANTO-JI

神社と寺が隣り合う風景

青岸渡寺は西国三十三所第一番札所。那智大社と隣接する配置から、熊野の神仏習合の歴史を感じられます。

  • 歴史ある本堂の落ち着き
  • 三重塔と那智の滝の重なり
  • 大社から寺へ自然につながる道
NACHI WATERFALL

御神体としての滝

那智の滝は景勝地であると同時に、飛瀧神社の御神体。大門坂から歩いて到達することで見え方が変わります。

  • 落差133mを一気に落ちる水
  • 滝壺へ近づくほど増す水音
  • 鳥居越しに仰ぐ御瀧

04 / CHOICES

雨・遅れ・疲れへの分岐

石畳は濡れると滑りやすく、バスは本数が限られます。「予定どおり歩く」以外の選択肢を先に共有しておきます。

小雨なら

滑りにくい靴とレインウェアで、歩幅を小さく。傘で片手をふさがず、石畳の苔を避けて歩きます。

強い雨・警報なら

大門坂を歩かず、車で那智山側へ移動。熊野那智大社・青岸渡寺・那智の滝を優先します。

10:10までに大社へ着かない

三重塔内部や土産時間を省き、11:25の滝到着と12:25のバス停待機を守ります。

12:34便に間に合わない

13:04発→13:09着、次に13:29発→13:34着へ。大阪出発も約30分ずつ後ろへ動かします。

05 / PRACTICAL

当日に効く実用情報

駐車場・バス

大門坂駐車場は無料で、トイレと屋根付き休憩スペースがあります。満車時は案内所や現地係員に代替駐車先を確認します。

  • 帰りの大門坂バス停を先に見る
  • バス時刻表をスマホに保存
  • 小銭と交通系ICの利用可否を当日確認

服装・持ち物

約740段の上りと、滝へ向かう下りを歩きます。観光地ですが、足元は街歩きよりトレッキング寄りです。

  • 滑りにくく履き慣れた靴
  • 両手が空くバッグ、飲み物
  • レインウェア、タオル、虫よけ

参拝・撮影

社寺では参拝を先に、撮影は周囲の動線をふさがない場所から。濡れた石段では歩きながら撮影しません。

  • 鳥居の前で一礼
  • 本殿・堂内の撮影表示を確認
  • 三脚より手持ちで短時間に

有料の追加体験

時間に余裕があれば、三重塔内部やお滝拝所舞台を選べます。両方入る場合は計20〜30分の余裕を見ます。

  • 三重塔：大人500円
  • お滝拝所舞台：現地で最新料金確認
  • 大樟胎内くぐり：護摩木または絵馬
