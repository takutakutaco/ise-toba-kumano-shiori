01 / SCHEDULE

旅の行程

DAY 1　9/21（月・祝）

大阪 → 伊勢 → 鳥羽 → 熊野市

  • 5:30大阪を出発
  • 8:00頃伊勢神宮・内宮を参拝
  • 9:15おはらい町・おかげ横丁を散策
  • 10:00〜10:40おかげ横丁で昼食
  • 11:15〜14:15鳥羽水族館を見学
  • 14:15熊野市へ移動（途中で休憩1回）
  • 18:00紀南荘にチェックイン・夕食

DAY 2　9/22（火・祝）

熊野市 → 那智山 → 大阪

  • 8:00紀南荘を出発
  • 9:00頃大門坂駐車場に到着
  • 9:15熊野古道・大門坂を歩き始める
  • 10:00頃熊野那智大社・青岸渡寺を参拝
  • 11:30頃那智の滝を見学
  • 13:30頃大阪へ出発（途中で休憩1回）
  • 19:30南森町でレンタカー返却
1日目は時間に注意。 紀南荘は18:00チェックインです。鳥羽水族館を出た後は休憩を1回に絞り、遅れそうなら宿へ連絡します。

02 / HIGHLIGHTS

この旅の見どころ

01

伊勢神宮・内宮

五十鈴川と森の参道を歩く、朝の静かな旅の始まり。

02

おかげ横丁

伊勢うどんや赤福を楽しめる、伊勢らしい門前町。

03

鳥羽水族館

ジュゴン、ラッコ、スナドリネコなどに会える3時間。

04

熊野古道・大門坂

杉並木と石畳が続く、熊野古道らしい参詣道。

05

熊野那智大社・青岸渡寺

熊野の信仰と歴史を感じられる社寺。

06

那智の滝

高さ133m。熊野観光を締めくくる大瀑布。
